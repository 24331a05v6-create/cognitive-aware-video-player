# 🧠 Cognitive-Aware Video Player

An AI-powered adaptive video learning system that adjusts playback based on user cognitive state using real-time facial analysis.

---

## 🎥 Demo Video

👉 [Watch Cognitive-Aware Video Player Demo](https://drive.google.com/file/d/1zUbW4C6oDmb7-iLq5o94X_tI4_zXFf6j/view?usp=sharing)

---

## 🚀 Features

- Real-time face & attention detection using OpenCV  
- Detects cognitive states: **Focused, Confused, Distracted**  
- Auto-pauses video when confusion is detected  
- Provides simplified explanations for better understanding  
- Dynamically adjusts playback speed based on engagement  
- Privacy-first approach (all processing done locally)

---

## 🛠 Tech Stack

- **Backend:** Python (Flask)  
- **Computer Vision:** OpenCV  
- **Frontend:** HTML, CSS, JavaScript
