# 🧠 Cognitive-Aware Video Player

An AI-powered adaptive video learning system that adjusts playback based on user cognitive state using real-time facial analysis.

## 🚀 Features
- Real-time face & attention detection (OpenCV)
- Detects states: Focused, Confused, Distracted
- Auto-pauses video when confusion is detected
- Suggests simplified explanations
- Adjusts playback speed dynamically
- Privacy-first (all processing done locally)

## 🛠 Tech Stack
- Python (Flask)
- OpenCV
- JavaScript / HTML / CSS
